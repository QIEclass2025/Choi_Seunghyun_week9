포켓몬 체스 게임.ver2 - 2025316001 양자정보공학과 최승현

이 게임은 이전 제출한 포켓몬 체스 게임의 업데이트 버전입니다.


### 게임 규칙 및 플레이 방법

1. 기본적인 규칙은 기존의 체스와 동일합니다.
    앙파상, 프로모션, 캐슬링 규칙이 전부 구현되어 있습니다.
2. 게임 파일 (chess_game.py) 을 실행하면 흑, 백 각자 풀, 불꽃, 물 중에서 원하는 타입을 선택합니다.
    체스 규칙 상 백이 선공인 것을 고려하여 흑이 먼저 타입 선택권을 갖습니다.
    각 타입의 포켓몬들은 모두 세대 별 스타팅 포켓몬 입니다.
3. 타입 선택이 끝나면, 포켓몬 스프라이트를 불러옵니다.
    !!이 단계에서 로딩 시간이 조금 걸릴 수 있습니다!!
4. 각자 선택한 타입의 포켓몬들을 가지고 체스를 플레이합니다.
5. 플레이 도중, 재시작 하고 싶다면 키보드 버튼 R을 누르면 됩니다.
6. 화면 오른쪽에는 기보와 상태 메시지가 출력됩니다.
    상태 메시지에는 본인 턴 표시 기능, 유효하지 않은 수 경고 메시지, 포켓몬 진화 시의 알림이 출력됩니다.
7. 상대의 말을 잡을 때마다 해당 기물의 외형이 진화합니다!
8. 게임이 종료되면, 재시작 버튼이 화면에 나타납니다.

#### 앙파상, 프로모션, 캐슬링 설명

1. 앙파상 : 상대 폰이 처음 두 칸 전진했을 때, 바로 다음 턴에 옆칸에 있는 내 폰이 그 폰을 잡듯이 지나가는 칸에서만 잡을 수 있는 특수 폰 이동 규칙.
2. 폰이 상대 진영 끝줄에 도착하면 원하는 다른 기물(주로 여왕)로 바꿀 수 있는 규칙.
3. 킹과 룩이 동시에 이동하며, 킹이 두 칸 이동하고 룩이 그 옆으로 뛰어오는 특수 수로, 킹과 룩이 아직 이동하지 않았고 중간 칸이 비어 있으며, 킹이 체크 상태가 아닌 경우에만 가능.
